# 配置发布

## 它解决什么问题

配置发布把域名/规则/WAF 变更变成可审批、可灰度、可回滚的版本，而不是保存即生效。

## 启用方式

配置发布没有全局开关，域名第一次成功发布版本后自动进入发布模式：

```text
domains.published_version_id != NULL
```

之后：

```text
保存修改
→ 只生成 config_version
→ 不会自动影响线上
→ 必须发布新版本
```

## 完整流程

```text
1. 修改域名 / 规则 / WAF
2. 配置发布 → 版本历史，确认新版本
3. 新建发布单
4. 选择域名和版本
5. 可选：选择灰度节点
6. 提交审批
7. 管理员审批通过
8. 发布
```

## 灰度

- 不选节点：立即全量发布。
- 选节点：先下发到目标节点，全部 apply-report 成功后再全量。
- 失败自动回滚。

## 判断是否已启用

```sql
SELECT name, published_version_id
FROM domains
WHERE name = 'cdn.example.com';
```

- `NULL`：未启用，保存即生效。
- UUID：已启用，使用该版本快照。

## 回滚

- 版本历史 → 回滚到某个版本。
- 发布单 → 回滚当前发布。
- 灰度失败自动回滚。

## 常见问题

| 现象 | 原因 |
| --- | --- |
| 规则测试器命中但线上不变 | 域名已启用发布，未发布新版本 |
| 发布按钮不可用 | 未审批 / 已有发布中的单 |
| 发布失败 | 节点 apply-report 失败、网络分区 |
| 回滚后仍旧 | Edge 未同步、版本未切换 |
