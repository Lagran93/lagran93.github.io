## 推荐上手顺序

1. [项目与域名](/use/domains)
2. [缓存规则与 Cache Key](/use/cache)
3. [刷新与预热](/use/prefetch)

## 菜单结构

```text
概览
加速服务
  ├─ 域名管理
  ├─ 缓存规则
  ├─ 缓存诊断
  ├─ WAF 防护
  ├─ 证书管理
  ├─ 缓存刷新
  └─ 缓存预热
配置发布
边缘节点
观测
  ├─ 统计分析
  ├─ 大屏监控
  ├─ 告警中心
  ├─ 访问日志
  ├─ 操作审计
  └─ 登录日志
系统
  ├─ 系统设置
  ├─ 项目管理
  └─ 用户管理
```

## 角色

| 角色 | 权限 |
| --- | --- |
| 管理员 | 全部项目、节点、用户、审计、系统设置 |
| 项目 owner/admin | 项目内读写 |
| 项目 member | 项目内只读 |
